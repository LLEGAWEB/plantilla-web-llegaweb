# Plantilla web Llegaweb

Plantilla maestra reutilizable para crear sitios web de pequeños negocios y profesionales.

## Contenido

- Portada principal
- Menú adaptable a dispositivos móviles
- Sección de servicios
- Sección de beneficios
- Testimonios
- Formulario de contacto
- Botón de WhatsApp
- SEO básico
- Diseño adaptable a teléfonos, tabletas y computadores

## Estructura

- `index.html`: contenido y estructura del sitio
- `css/styles.css`: colores, diseño y versión móvil
- `js/app.js`: menú móvil, año automático y formulario
- `assets/images`: fotografías del cliente
- `assets/icons`: logotipos e iconos

## Cómo reutilizar la plantilla

1. Crear una copia de esta carpeta.
2. Cambiar el nombre de la copia por el nombre del cliente.
3. Reemplazar textos, colores, imágenes y logotipo.
4. Actualizar el título y la descripción SEO.
5. Cambiar el número del botón de WhatsApp.
6. Configurar el formulario de contacto.
7. Revisar la versión móvil.
8. Crear un repositorio Git propio para el cliente.

## Personalización rápida

Los colores principales se encuentran al comienzo de `css/styles.css`, dentro de `:root`.

El número de WhatsApp se encuentra en `index.html`:

`https://wa.me/56900000000`

El número debe incluir el código del país, sin espacios ni símbolos.
